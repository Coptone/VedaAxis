# VedaAxis 项目进度

> 最近更新：2026-08-05
>
> 当前测试版：`0.1.3`
>
> 进度口径：`已完成` 表示已有可复现的验证证据；`进行中` 表示代码或样板已存在，但仍缺少 PRD 要求的完整验收；`待开始` 表示尚未进入实现。

## 当前结论

VedaAxis 已形成可构建的 Web、API、Dalamud 插件和共享契约 MVP 基线，并已打通 GitHub/Gitee 代码托管与 Dalamud 自定义仓库分发。当前主线仍处于“阻断 PoC + MVP 实机验收”阶段，不把编译通过等同于国服实机通过。

当前优先级：

1. 完成 `POC-02` 原生热键栏高亮实机矩阵，保存诊断、截图或录像和版本信息。
2. 完成 `POC-01` 国服 Dalamud 事件链验证，确认战斗、团灭、Boss Action 和本地 ActionEffect 信号。
3. 收敛 `POC-04` DMU 阶段语义和绝对时间基准，使 FFLogs、插件实机与上游时间轴使用同一套锚点定义。
4. 在上述证据稳定后，再把当前 MVP 基线推进为可持续扩展的产品版本。
